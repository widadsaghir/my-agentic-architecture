  • Arbitration : Selected Amazon Bedrock over AWS PrivateLink with Guardrails.

🟣 Decision 3: Database Modernization
Amazon Aurora vs Oracle Exadata
  • Arbitration : Re-platformed relational persistence to Aurora PostgreSQL Multi-AZ.
  • Impact : 35% reduction in licensing run costs; automated multi-zone failover under 30s.

Human-in-the-Loop Thresholds
  • Arbitration : Imposed mandatory human approval for financial settlements > 2,000 EUR.
